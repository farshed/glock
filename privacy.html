Glock – Privacy Policy

Last updated: 25 July 2026

Glock is a browser extension that shows a lines-of-code badge on GitHub repository pages. It does all of its work on your own machine.

What we collect

Nothing. Glock has no server and no backend. We do not receive the repositories you visit, your access token, or anything else. There is no analytics, no tracking, and no telemetry of any kind.

How it works

When you open a repository page, the extension fetches the repository from GitHub and counts its lines entirely inside your browser. Repository contents are held in memory only for as long as the count takes, and are never written to disk or sent anywhere.

The only network requests it makes are to GitHub. Those requests are subject to GitHub's privacy policy.

Your GitHub token

You can optionally add a personal access token so private repositories can be counted. It is stored locally in your browser and sent only to GitHub. It is never sent to us or to anyone else.

Delete it at any time by clearing the field in the extension's options, or by removing the extension.

What is stored on your device

  • Your access token, if you added one.
  • Your maximum repository size setting.
  • Line counts for repositories you have viewed, cached briefly so repeat visits are instant.

All of this lives in the browser's extension storage and stays on your device. Removing the extension removes it.

Sharing

We have nothing to share. No data reaches us, so none of it can be sold, rented, or passed to a third party.

Contact

Questions about this policy can be sent to mail@farshed.me.

Glock is open source – the code that does all of the above is at github.com/farshed/glock.
